# 今日の進捗 — 要件定義（運用本線）

**版:** 2.1  
**関連:** [`DAILY_PROGRESS_SETUP.md`](./DAILY_PROGRESS_SETUP.md)

## 目的

当日タスクを約1分で回答し、スプレ集計ではなくボードのレーンを更新する。  
ボードを普段開かない人には定時通知で回答 URL を届ける。

## やること

- ボード内「今日の進捗」UI（**途中 / 夕** の2枠）
- 進捗 → ToDo / Doing / Done
- 追加タスク申告（既存 / 新規 Backlog。MTG もタスク名で申告）
- GAS による定時通知（Chat Webhook またはメール）

## やらないこと

- スプレ日次集計
- カレンダー API
- Chat 内だけの別マスタ
- **必須としての** Chat カスタムアプリ（DM・カードボタン）
- 朝枠 UI（デイリー MTG で確認）

## 仕組み

```text
GAS（定時）→ Chat Webhook / メール（リンク）
                ↓
        今日の進捗 UI → Firestore（正本）
```

## 通知枠

| 枠 | 目安 | 内容 |
|----|------|------|
| 途中 | 12:00 / 15:00 | 未完了タスクの進捗 + 追加タスク |
| 夕 | 17:00 | 進捗 + 追加タスク |

## 当日タスク条件

担当に本人 / startDate〜dueDate に当日 / cant 除外 / 日付なし除外
