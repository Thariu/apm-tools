# 使い方（公開後）

サイトが開いたあとの操作です。公開そのものは [SETUP.md](./SETUP.md) を参照してください。

チームのブラウザで同じボードを開くと、追加・編集・ドラッグが **ほぼリアルタイムで共有** されます。

## 1. 入る

ログイン画面が出る場合は、チームで決めた共通の ID とパスワードを入力します。ログイン画面が出ない場合は、そのままボードが開きます。

## 2. 画面の見方

ヘッダーの左がタイトル「アジャイルプランニングボード」です。その右にタブがあります。

- **カテゴリ / カテゴリ2 / カテゴリ3**（初期名）… 案件ごとのプランニングボード。名前はクリックして変えられます
- **カテゴリ管理** … カテゴリの追加・並び替え・アーカイブ
- **メンバー別タスク** … 担当者ごとのスケジュール
- **今日の進捗** … 当日の進捗申告
- **振り返り** … スプリント末の振り返り

右上に **Sprint:** と週の表示が出ることがあります。

## 3. プランニングボード

1 つのカテゴリは、横に並んだ列です。

- **Backlog** … 案件（親）。左の列。下の「＋」で親 Backlog を追加できます
- **ToDo / Doing / Done / Can't** … その案件にぶら下がるタスクの状態

タスクのカードでは次ができます。

- 名前をクリックして編集
- 担当者を付ける
- **期間** をクリック → カレンダーで日を選ぶ → **確定**（1 日だけ選ぶと着手・完了がその日になります。別の日をもう一度選ぶと期間になります）
- 予定工数（時間）を入れる
- カード左の「⋮⋮」をつかんで、列のあいだをドラッグして移動する
- 列の「＋」でタスクを追加する

スプリントゴールや曜日の担当も、ボード上で編集できます。

## 4. カテゴリの追加・名前変更

- **名前の変更**: いま開いているカテゴリタブの名前をクリックして入力する
- **追加**: **カテゴリ管理** → **＋ カテゴリを追加**
- **並び替え**: カテゴリ管理の一覧で ⠿ をドラッグする
- **アーカイブ**: 一覧から一時的に非表示。あとから **復元** できます。不要なら **完全削除**（中のタスクも消えます）

最後の 1 つはアーカイブできません。

## 5. メンバー別タスク

ヘッダーの **メンバー別タスク** を開きます。タスクに **担当者** と **期間** が入っていると、人ごとの表に並びます。

## 6. 今日の進捗

ヘッダーの **今日の進捗** を開きます。画面内に **途中** / **夕** タブがあります。

- **途中** … 未完了の当日タスクと進捗
- **夕** … 当日タスクの最終回答

進捗を更新すると、ボード上の ToDo / Doing / Done も変わります。定時の Chat 通知は、別途 [DAILY_PROGRESS_SETUP.md](./DAILY_PROGRESS_SETUP.md) です。

## 7. 振り返り

ヘッダーの **振り返り** を開きます。今スプリントのメモや幸福度などを残します。スプリントが終わると過去分として残ります。

## 8. 初期データ

初めて開いたとき、サンプルのカテゴリ・担当（佐藤 / 田中 / 針生）・タスクが入ることがあります。消したり書き換えたりして使って問題ありません。
